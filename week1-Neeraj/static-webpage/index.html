EC2 Static Website Hosting

Apache HTTPD Server Deployment on Linux Instance

Cloud Beginner Project ☁️

📖 About Project

This website showcases how a simple static HTML page can be hosted on a cloud server. Using AWS EC2 and Apache HTTPD, the page becomes publicly accessible over the internet.

🛠 Deployment Workflow

✔ Create EC2 instance and configure security group
✔ Connect to server using SSH
✔ Install Apache Web Server
✔ Upload HTML file to web root directory
✔ Start service and test in browser

🚀 Key Learnings

  • Basic Linux commands
  • Web server configuration
  • Cloud networking basics
  • Public IP access

✅ Result

Successfully deployed a static webpage in AWS demonstrating how web servers host content and deliver it to users globally.
